## Summary

Admin Fulfillment Dashboard QoL improvement: Qty column with hover preview flyout. Enables quick-glance order identification without clicking into order details - reduces clicks to ~0 for small orders.

## Changes

### Qty Column (Feature 1)

- **New column:** "Qty" inserted between "Order #" and "Buyer Name"
- **Value:** Sum of line item quantities (not distinct SKUs)
- **Styling:** Centered, narrow width, bold text

### Hover Preview Flyout (Feature 2)

- **Trigger:** Mouse hover on Qty cell
- **Content:** First 3 cards displayed side-by-side with:
  - Card thumbnail (104×146px)
  - Card name (104px max, ellipsis truncation)
  - Quantity badge (if >1 copy)
- **"+More" indicator:** Shown for orders with >3 cards
- **Performance:** Lazy-loaded on first hover, cached per order ID

### Backend Preview Endpoint (Feature 3)

- **New endpoint:** `GET /api/cm-admin/fulfillment/orders/:source/:id/preview`
- **Response:** `{ ok, totalQty, hasMore, items: [{ name, imageUrl, quantity }] }`
- **Image enrichment:** Uses TCGDex adapter with existing cache
- **Timeout:** 3s for TCGDex lookups (fast, non-blocking)
