## Summary

Admin Fulfillment Order Details: Market-derived per-item pricing with "Market Est." column + lazy-loaded card image preview. Uses hybrid PPT (primary) + TCGDex (fallback) pricing architecture.

## Changes

### Market-Derived Pricing (G1)

- **New column:** "Market Est." added to order items table (preserves original Unit/Total columns for Stripe transaction prices)
- **Hybrid pricing:** PPT-first (condition-aware) with TCGDex fallback (free API, NM-only with condition discounts)
- **Condition normalization:** Standardizes "Near Mint" → "NM", "Lightly Played" → "LP", etc.
- **Price source badges:** PPT (blue) or TCGD (yellow) badge indicates data source

### Lazy Image Preview (G2)

- **Click-to-reveal:** Clicking card name shows inline thumbnail
- **Hover flyout:** Larger preview appears on hover over name/thumbnail
- **Image source:** TCGDex card images (`/high.webp` format)

### TCGDex Adapter

- **New service:** `tcgdexAdapter.ts` - Free Pokemon TCG API client with caching
- **Split TTL:** 7-day identity cache, 24-hour price cache
- **Set mapping:** 50+ Pokemon TCG sets mapped to TCGDex IDs (including dotted sets like `swsh12.5`, `sv03.5`)
- **Reliability:** 5s fetch timeout, graceful degradation on failure

### Order Item Enrichment Service

- **Orchestration:** Coordinates PPT + TCGDex lookups with concurrency limiting (3 parallel)
- **Per-item timeout:** 8 seconds max per item
- **Condition discounts:** NM=1.0, LP=0.85, MP=0.70, HP=0.50, DMG=0.30 for TCGDex fallback

## Risk Assessment

- **Scope:** Admin fulfillment order details (operator-only)
- **Blast radius:** Limited to orders viewed with `?enrich=true`
- **Guardrails:**
  - Enrichment failures return gracefully (page never hangs)
  - Per-item timeout (8s) and concurrency limit (3)
  - External API timeouts (5s) with AbortController
