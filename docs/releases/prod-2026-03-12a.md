## What Ships

### cardmint-search-app (service on :4310)

**Reference corpus fallback now functional:**
- `ReferenceAdapter` redirected from non-existent `tcg_search_corpus` to `tcg_snapshots + tcg_rows` — search now falls back to TCGPlayer catalog data when inventory returns zero candidates
- Representative-row deduplication: one candidate per card identity (product_name, set_name, card_number), LP-preferred pricing, `conditionBucket = "UNK"` always for catalog results
- `likeSearch` is set-constrained when the parsed query includes a set name (prevents cross-set inflation)
- Graceful empty-state: if no complete snapshot exists, all search paths return `[]` without errors
- `getDbStatus` health probe degrades `reference.connected = false` when `tcg_rows`/`tcg_snapshots` tables are absent (wrong-schema or mispointed DB), surfacing clearly rather than appearing healthy

### EverShop Search Extension (`cardmint_search`)

**Visual source distinction + operator confirmation gate:**
- Inventory results auto-resolve to working card as before (IN STOCK badge, green border)
- Catalog reference results **never auto-promote** — operator must click "Confirm catalog match" explicitly (CATALOG MATCH badge, amber button)
- `conditionBucket = "UNK"` shows "Condition unassessed" subtitle in both working card and disambiguation table
- Source copy: "Found in your inventory" vs "Not in inventory — market reference · Source: TCGPlayer [date]"
- Amber warning in status bar when reference corpus is empty or misconfigured, linking to TCG Dashboard upload
