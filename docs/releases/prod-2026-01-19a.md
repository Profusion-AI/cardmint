# Release: prod-2026-01-19a

**Date:** 2026-01-19
**Type:** Feature (Fulfillment + Storefront)
**Complexity:** ★★★☆☆ (new DB column, API endpoint, frontend components)

## Summary

Two features bundled in this release:

1. **PWE (Plain White Envelope) workflow** — Allows operator to mark low-value shipments (1-3 cards, < $7.49) for stamp mail instead of purchasing an EasyPost label.

2. **Email capture improvements** — Cross-component state sync, responsive popup width, and footer-level inline newsletter capture.

## Changes

### PWE Workflow (Fulfillment)

| Component | Change |
|-----------|--------|
| DB Migration | `is_pwe` INTEGER column on `marketplace_shipments` (default 0) |
| Backend API | `PATCH /api/cm-admin/marketplace/shipments/:id/pwe` — Toggle PWE flag with audit logging |
| Backend Guard | Label purchase endpoint returns 400 `PWE_SHIPMENT` if `is_pwe === 1` |
| EverShop Proxy | `PATCH /api/marketplace/shipments/:id/pwe` — Proxies to backend with Bearer auth |
| UnifiedGrid UI | Gray (#a6a6a6) row background + orange (#E65100) text for PWE candidates |
| Actions UI | "Mark PWE" / "Undo PWE" buttons with confirmation modals, PWE badge |

**Business logic:**
- Highlights orders with 1-3 cards AND (product + shipping) < $7.49
- Operator manually marks these as PWE → hides "Purchase Label" button
- Shipment still tracked, just fulfilled via stamp mail (no tracking number)

### Email Capture (Storefront)

| Component | Change |
|-----------|--------|
| `useEmailCapture.ts` | New hook for cross-component state sync via custom events |
| `EmailCapturePopup.tsx` | GameBoy-styled popup with responsive width (`clamp(300px, 90vw, 400px)`) |

**Note:** /vault now shows two inline captures (vault + footer). This is intentional for increased newsletter visibility.

## Migration

**Forward-only migration** — SQLite cannot DROP COLUMN. If rollback needed, `is_pwe` column remains but is unused.

```sql
-- Up
ALTER TABLE marketplace_shipments ADD COLUMN is_pwe INTEGER DEFAULT 0;
CREATE INDEX IF NOT EXISTS idx_marketplace_shipments_is_pwe ON marketplace_shipments(is_pwe);

-- Down (index only)
DROP INDEX IF EXISTS idx_marketplace_shipments_is_pwe;
```
