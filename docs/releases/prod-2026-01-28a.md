## Summary

TCGDex adapter reliability improvements: localId retry variants, best-match set resolution, denominator-based set inference, and card name validation. Fixes "half the rows missing" issue where deterministic mismatches caused Market Est. and card images to fail.

## Changes

### LocalId Retry Variants (Fix 1)

- **New method:** `generateLocalIdVariants()` - produces raw, stripped, and pad3 variants
- **Example:** "055/072" → ["055", "55", "055"] (unique variants tried in order)
- **Cache-first:** Checks all variants in cache before any network calls
- **Benefit:** Fixes cards like "Shining Fates 055/072" (needs localId "55" not "055")

### Best-Match Set Resolution (Fix 2)

- **Changed:** `resolveSetId()` now collects ALL partial matches and picks longest
- **Benefit:** "Sword & Shield Base Set" → `swsh1` (not WotC `base1`)
- **Same logic for API fallback:** Longest name match wins

### Denominator-Based Set Inference (Fix 3)

- **New method:** `parseDenominator()` - extracts Y from "X/Y" format
- **New index:** `officialCountIndex: Map<number, string[]>` - built from TCGDex `/sets`
- **Fallback behavior:** When set resolution fails or all variants 404:
  - Get candidate sets with matching `cardCount.official`
  - Try each candidate with localId variants
  - Validates card name to avoid wrong-set matches
- **Cap:** Max 25 candidate sets tried to prevent excessive API calls

### Card Name Validation (Fix 4)

- **New signature:** `getCardBySetAndNumber(setName, cardNumber, opts?: { cardName? })`
- **New method:** `normalizeCardName()` - strips parentheticals like "(Full Art)"
- **Validation:** During cache lookup and API fetch, compares expected vs actual name
- **Benefit:** Prevents wrong-set matches during inference

### Debug Logging (Fix 5)

- **New method:** `logFailedLookup()` with failure classification:
  - `localid_mismatch` - Some variants 404 but later succeeded
  - `set_mismatch` - All variants 404 for resolved set
  - `set_unresolved` - Could not resolve set ID
  - `set_inference_failed` - Denominator-based inference failed
  - `timeout` - API timeout
  - `api_error` - Other API errors
- **Logged data:** setName, cardNumber, cardName, resolvedSetId, denominator, attemptedIds
